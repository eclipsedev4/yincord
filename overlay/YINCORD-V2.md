# Yincord V2

Windows desktop fork in progress. The release is called Yincord V2; the application name is Yincord.

## Current state

Source has been imported from Fluxer. Initial product labels and Windows notification identity are customized. This is not yet a built or release-ready application.

The dependency installation stopped because the local drive ran out of space. No complete compilation or runtime verification has passed. A remote build environment is needed before an installer can be delivered.

Before release: complete icon and installer branding, isolate update feeds and protocol identifiers, configure a compatible backend, compile renderer WASM and desktop bundles, and test sign-up, DMs, friends, servers, notifications and calls on Windows.

The existing Sharkord server is not compatible with the Fluxer client. Upstream network endpoints remain in this development source and must be reviewed before distribution. Existing Yincord accounts have not been migrated.
